# Stanley Eke Portfolio

Professional portfolio website for Stanley Eke, a London-based 2nd Line IT Support Engineer.

## Stack

- React 19
- TypeScript
- Vite
- Lucide React
- Responsive custom CSS

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Main folders

- `src/` — website application and styles
- `public/` — downloadable CV and public assets
